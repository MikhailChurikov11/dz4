Описание логики

Подключение библиотек. stdio.h — для printf/scanf,

locale.h — для корректного отображения кириллицы в консоли Windows.

Директива _CRT_SECURE_NO_WARNINGS отключает предупреждение MSVC о «небезопасности» scanf.

Ввод. Два целых числа A и B (показания датчиков traffic flow) считываются через scanf("%d %d", &A, &B).

Проверка чётности. Число чётное, если остаток от деления на 2 равен 0 (A % 2 == 0), иначе — нечётное (A % 2 != 0).

Условие «только одно чётное» строится из двух «ИЛИ»-веток:
(A % 2 == 0 && B % 2 != 0) — A чётное, B нечётное;
(A % 2 != 0 && B % 2 == 0) — A нечётное, B чётное.

Если хотя бы одна ветка истинна — знак показывает «Налево».
Альтернатива через XOR. Так как A % 2 даёт 0 (чётное) или 1 (нечётное), выражение (A % 2) ^ (B % 2) тоже даёт 1 только при разных чётностях — это та же логика короче.

Вывод. Печатается 1 (Налево) или 0 (не Налево).
